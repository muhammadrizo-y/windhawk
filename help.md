# Set up Windhawk

This extension needs **Windhawk v2.0 alpha 3 or newer**. It won't work with 1.x versions.

1. Open the [Windhawk releases page](https://github.com/ramensoftware/windhawk/releases).
2. Download the latest **v2.0 alpha** release.
3. Run the installer.
4. Click **Continue**. If you installed Windhawk somewhere other than the default location, first set **CLI Path** to your `windhawk-cli.exe`.
